# Proyecto 5: Catálogo de cursos con React y Vite

Este es uno de mis primeros proyectos creando aplicaciones con **React y Vite**. Es una página de práctica inspirada en un catálogo de cursos: muestra una barra de navegación y una sección de cursos destacados con tarjetas informativas.

## Qué incluye

- Una barra de navegación con enlaces de ejemplo, el logotipo y una opción para registrarse.
- Una sección de cursos destacados compuesta por tarjetas con categoría, descripción, nivel y duración.
- Componentes de React separados para la navegación y las tarjetas, con estilos CSS propios.
- Vite para ejecutar el servidor de desarrollo y generar la compilación de producción.

El proyecto me permitió practicar la composición de una interfaz con componentes reutilizables en React y aplicar estilos para organizar sus distintas secciones.

## Tecnologías

- React
- Vite
- JavaScript
- CSS

## Cómo ejecutar el proyecto

Necesitas tener instalado Node.js y npm. Desde la carpeta del proyecto, ejecuta:

```bash
npm install
npm run dev
```

Vite mostrará en la terminal la dirección local para abrir la aplicación en el navegador.

## Comandos disponibles

- `npm run dev`: inicia el servidor local de desarrollo.
- `npm run build`: genera la versión de producción en `dist`.
- `npm run preview`: sirve localmente la compilación generada.
- `npm run lint`: ejecuta ESLint para revisar el código.
